## 📖 Sobre o Projeto

**Raiz Floral** é um e-commerce conceitual de cosméticos naturais, veganos e cruelty-free. O projeto foi desenvolvido como parte do meu portfólio para demonstrar habilidades em desenvolvimento front-end, design de interfaces e experiência do usuário.

O site apresenta uma identidade visual acolhedora e elegante, com paleta de cores inspirada na natureza (dourado, rosa, verde e marrom), tipografia sofisticada e interações suaves.

### 🎯 Objetivo

Criar um site de apresentação completo e funcional para uma marca fictícia de cosméticos naturais, demonstrando:

- ✅ Estrutura HTML semântica e acessível
- ✅ Design responsivo (mobile-first)
- ✅ Estilização avançada com CSS3 (variáveis, animações, flexbox, grid)
- ✅ Interatividade com JavaScript puro (sem frameworks)
- ✅ Persistência de dados com localStorage
- ✅ Boas práticas de UX/UI

---

## ✨ Funcionalidades

### 📱 Página Inicial (Home)
- Banner principal com chamada para ação
- Selos de qualidade (100% Natural, Cruelty-Free, Sustentável, Feito com amor)
- Categorias em destaque
- Produtos em destaque com carrinho
- Depoimentos de clientes
- Newsletter para captura de leads

### 🛍️ Produtos
- Grade de produtos com imagem, nome, descrição, preço e selos
- Filtros por categoria (Todos, Hidratantes, Sabonetes, Óleos, Perfumes)
- Busca por nome, descrição ou selo
- Botão "Adicionar ao carrinho" com feedback visual

### 📖 Sobre
- História da marca
- Missão, Visão e Valores
- Valores em detalhe (8 princípios)
- Equipe (4 membros)
- Linha do tempo com marcos importantes

### 📞 Contato
- Formulário com validação em tempo real
- Máscara de telefone automática
- Informações de contato (endereço, e-mail, telefone, horário)
- Redes sociais
- Mapa (placeholder)

### 🛒 Carrinho
- Lista de produtos adicionados
- Controles de quantidade (+ e -)
- Remoção de itens
- Resumo do pedido (subtotal, frete, total)
- Cupons de desconto (RAIZ10, FLORAL20, MEL15, NATURAL5)
- Finalização de compra com confirmação

## 🎨 Identidade Visual

### Paleta de Cores

| Cor | Hex | Uso |
|-----|-----|-----|
| **Dourado** | `#D4A373` | Botões, destaques, hover |
| **Rosa seco** | `#F5D6D0` | Fundos suaves, cards |
| **Verde sálvia** | `#A8C4A0` | Selos, badges |
| **Off-white** | `#FEF9F4` | Fundo principal |
| **Marrom** | `#5C4B3A` | Textos |

### Tipografia

| Elemento | Fonte | Uso |
|----------|-------|-----|
| **Títulos** | Playfair Display | Elegância e sofisticação |
| **Corpo** | Inter | Legibilidade e modernidade |

### Elementos Visuais
- Sombras suaves para profundidade
- Bordas arredondadas para acolhimento
- Animações sutis (fadeIn, hover, transições)
- Ícones emoji para personalidade
- Gradientes para profundidade

## 🛠️ Tecnologias Utilizadas

### Front-end
- **HTML5** - Estrutura semântica e acessível
